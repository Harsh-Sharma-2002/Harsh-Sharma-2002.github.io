About

I'm a Computer Science M.S. student at Arizona State University focused on building agentic AI systems, observability infrastructure, and ML-backed software, with hands-on experience across backend services, ML pipelines, and cloud-native infrastructure.

As an Agentic AI Guide and Course Developer for ASU's Semantic Web Mining course, I designed and built Agent Harness, a multi-agent orchestration platform built from scratch with LangGraph, FastAPI, and Streamlit, and use it as the course's hands-on teaching tool for agentic system design.

As a Graduate Researcher in the VISA Lab, I work on process mining and agentic AI, building a LangGraph-based digital twin over real-world event logs that grounds LLM agent reasoning in structured process context instead of free-form generation.

Earlier in my path, I built RepoScope, a repository-aware retrieval system for LLM-based code review, and worked on ML infrastructure for EEG signal classification and financial time-series anomaly detection. Across all of it, I care about the same thing: treating AI systems as engineered software, with explicit control, structured outputs, and full observability, not black-box demos.
